WhateverFont is a tool that lets you create entire fonts from a description. You can use AI to create completely new fonts, or use the engine to remix existing ones. The tool is made to be customizable and rapidly iteratable, and supports English, Español, Français, Deutsch, Português, Polski, Čeština, Türkçe, Tiếng Việt, Íslenska, Yorùbá, ʻŌlelo Hawaiʻi, Azərbaycanca, Ελληνικά, Русский, Українська, العربية, हिन्दी, 日本語, 简体中文, 繁體中文, 한국어 and more.

Every font starts with @COUNT@ characters

Every font that WhateverFont draws starts with GF Latin Core, the set that Google Fonts requires: Western, Central and Eastern European, Turkish, Baltic and Welsh letters, the common signs, and combining marks that attach to any letter. On top of that come the Vietnamese alphabet, Pinyin, letters for Azerbaijani, Hawaiian, Yoruba, Igbo and Hausa, fractions, small figures above and below the line, more currency and math signs, arrows and shapes. Modern Greek and Cyrillic are in it too: Russian, Ukrainian, Belarusian, Bulgarian, Serbian, Macedonian and Kazakh. Point at a character to see its name.

How it works

The agent doesn’t draw outlines. It picks numbers like weight and contrast and writes a short recipe for each letter. WhateverFont does the rest.

  1. Skeleton

    A recipe draws each letter as centerline strokes: a stem, a ring, an arch, a bowl.

  2. Pen

    An elliptical pen gives the strokes their thickness. One number sets the contrast and another the stress angle. Stems can swell into flares.

  3. Spacing

    Each side of a letter is straight, round, diagonal or open, and gets a sidebearing to match. Kerning then fixes the pairs that remain.

  4. Compile

    fontTools writes TTF and WOFF2 for each style, and one variable font with every axis.

  5. Look

    Proofs come from the built files, shaped with HarfBuzz. The agent looks, measures, and edits until the proofs are right.

Get started

WhateverFont is a Python package and a skill for coding agents. It needs Python 3.10 or later.
